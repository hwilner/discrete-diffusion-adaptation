# DiDA Architecture

This document provides a detailed explanation of the Discrete Diffusion Adaptation (DiDA) architecture as implemented in this repository. The implementation is based on the Emu3.5 paper (arXiv:2510.26583).

## 1. Overview

DiDA is an inference-time adaptation that transforms the generation of visual tokens from a sequential, token-by-token process into a parallel, bidirectional one. This is achieved by framing image generation as a **discrete diffusion process**.

Key characteristics:

- **Parallel Generation:** All image tokens are generated simultaneously.
- **Iterative Denoising:** The generation process starts with random noise and iteratively refines the tokens over a series of denoising steps.
- **Hybrid Attention:** A special attention mechanism is used to allow noisy tokens to attend to each other bidirectionally, while clean tokens maintain a causal attention pattern.

## 2. Discrete Diffusion Process

The core of DiDA is a discrete diffusion process, which is defined by two main components:

### 2.1. Forward Process (Noise Addition)

In the forward process, noise is gradually added to clean image tokens over a series of timesteps. For discrete data like tokens, this is achieved by randomly replacing tokens with other tokens from the vocabulary.

The `DiscreteDiffusionScheduler` class manages this process. The `add_noise` method implements the noise addition, where the probability of a token being replaced is determined by the noise schedule (`alphas_cumprod`).

### 2.2. Reverse Process (Denoising)

The reverse process is where the generation happens. Starting from a sequence of completely random tokens (pure noise), the model iteratively denoises the sequence to recover the clean image tokens.

The `DiDACore` model is responsible for predicting the clean tokens from the noisy ones at each timestep. The `denoise_step` method performs a single step of this process.

## 3. DiDA Core Model

The `DiDACore` model is a standard transformer architecture with a few key modifications:

- **Timestep Embedding:** The model takes the current diffusion timestep as an input. This is embedded and added to the token embeddings, allowing the model to be aware of the current noise level.
- **Hybrid Attention Mask:** The model uses a special attention mask, generated by `DiDAAttentionMask`, to control the information flow between tokens.

## 4. Hybrid Attention Mechanism

The key innovation of DiDA is its hybrid attention mechanism, which is crucial for enabling parallel generation while maintaining coherence with the conditioning text.

The attention mask is constructed as follows:

- **Clean Tokens (Text and Image):** These tokens follow a standard causal attention pattern, meaning they can only attend to preceding tokens.
- **Noisy Tokens (Image):** These tokens can attend to:
    - All preceding clean tokens (causally).
    - All other noisy tokens within the same image (bidirectionally).

This allows the model to use the information from the entire noisy image sequence to predict the clean tokens at each step, which is what enables the parallel generation.

The `DiDAAttentionMask.create_dida_mask` method implements the creation of this mask.

## 5. Sampling and Inference

The `DiDASampler` class orchestrates the entire generation process. It provides methods for:

- **`sample`:** Pure image generation, where all tokens are generated in parallel.
- **`sample_interleaved`:** Text-to-image generation, where the model generates image tokens conditioned on a given sequence of text tokens. In this case, the text tokens remain fixed, and only the image tokens are denoised.

The `DiDAInference` class provides a high-level API for these generation tasks, abstracting away the details of tokenization and sampling.

## 6. Comparison to Autoregressive Generation

| Aspect                | Standard Autoregressive        | DiDA                           |
|-----------------------|--------------------------------|--------------------------------|
| **Image Generation**  | Sequential (one token at a time) | Parallel (all tokens at once)  |
| **Text Generation**   | Sequential                     | Sequential (unchanged)         |
| **Inference Speed**   | Baseline                       | ~20x faster for images         |
| **Attention Pattern** | Causal only                    | Hybrid (causal + bidirectional)|
